# 深智榜單日報

天瓏及博客來的深智出版社榜單工作台，使用 Browser Use + DOM 讀取可見頁面並保存原站截圖。網站採靜態 HTML/CSS/JavaScript，支援站別、榜單、7 日／30 日篩選、書名搜尋、單本截圖下載、CSV 匯出與全部截圖 ZIP。

## 本次資料

- 查核日期：2026-09-29，Asia/Taipei。
- 天瓏：繁體中文全分類，近 7 天與近 30 天，各前 100 名。
- 博客來：中文書總榜、電腦資訊榜，7 日與 30 日，各前 100 名。
- 天瓏未確認有跨語言全站總榜或獨立電腦資訊總分類榜，不能把繁體中文榜稱為以上兩榜。
- 以天瓏深智出版社分頁書目比對 ISBN 或去除空白／標點的書名；疑似差異另核對商品頁出版社。書目可能更新或省略售罄商品，找不到的結果只能陳述比對範圍。
- 保存 71 筆上榜紀錄的書籍截圖。不同週期上榜的同一本書分別保存。
- 榜單截圖移除天瓏「最後瀏覽商品」區，避免刊出使用者瀏覽紀錄。

## 使用

開啟 `outputs/index.html` 即可使用。所有截圖以相對路徑保存，不需第三方圖片 CDN。公開網站從本 repository 的 `gh-pages` branch 提供。

本機預覽可用 `node scripts/serve.mjs`，然後開啟終端機顯示的網址。

## 每日更新

每天台灣時間 09:00 由 Codex 此聊天的 automation 執行。具體程序見 `UPDATE.md`。這不是網頁前端直接抓取書店資料；更新需要本機 Codex 環境、瀏覽功能與 GitHub 權限可用。

正常瀏覽、逐頁讀取，避免不必要的重新整理。遇到 CAPTCHA、403 或驗證頁停止該站並標示未完成，通知使用者接手；不使用 stealth、代理輪替或驗證繞過。

歷史資料存於 `outputs/data/YYYY-MM-DD.json`。請保留原始名次、實際查核時間與來源。不同週期不可當成日對日排名變化；只有相同榜單的不同查核日期才能計算升降。

## 檔案

- `outputs/index.html`、`style.css`、`app.js`：網頁。
- `outputs/data.js`：目前報表資料。
- `outputs/data/`：依日期保存的報表。
- `outputs/cards/`：單本原站截圖。
- `outputs/screenshots/`：榜單原頁截圖。
- `scripts/prepare-data.mjs`：將查核資料與 DOM 座標轉換為卡片截圖及報表。
- `scripts/publish.mjs`：只發布 `outputs/` 白名單檔案到 GitHub Pages。

未提供虛構資料、即時排名或尚未累積的升降趨勢。書籍封面與書店畫面權利屬原權利人；本站保留來源連結。
